# EOE演讲线上助手小程序

面向 EOE 中文演讲俱乐部的线上协作工具，为 Toastmasters 例会提供活动发现、角色报名、计时、投票、会议纪要和成员管理能力。

## 功能

- 活动广场与例会详情
- 例会角色报名与主持人控制台
- 时间官计时与现场投票
- 会议纪要及获奖结果
- 俱乐部成员与个人资料
- 官员管理后台

## 技术栈

- 微信小程序原生开发
- WXML、WXSS、JavaScript

## 开发

1. 使用微信开发者工具打开本目录。
2. 在 `project.config.json` 中配置小程序 AppID。
3. 根据开发环境调整 `utils/config.js` 中的 API 地址。
4. 编译并运行项目。
